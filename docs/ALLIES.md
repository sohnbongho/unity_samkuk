# 아군(동행 장수)

장수를 고른 뒤 나머지 장수 중 **최대 2명**을 아군으로 데려갑니다. 아군은 주인공을 따라다니며 자기 장수의 시작 무기로 자동 공격하고,
**적에게 공격받아 체력이 다하면 쓰러졌다가 일정 시간 뒤 되살아납니다.**

## 흐름

1. 게임 시작 → 장수 선택(1~5 키/클릭)
2. 이어서 **아군 선택 화면**: 고른 장수를 뺀 4명 중 최대 2명을 고른다
   - 카드를 클릭하거나 `1`~`4` 키로 고르고 다시 누르면 해제, 정원이 차면 먼저 고른 장수가 빠지고 새로 고른 장수가 들어간다
   - `출발` 버튼 또는 `Enter`/`Space` 로 확정, **0명도 가능**
   - 지난번에 고른 아군은 미리 선택되어 있다 (`GameSession.SelectedAllies`)
3. 게임 시작 (선택하는 동안은 시간이 멈춘다)

## 아군의 행동

| 항목 | 내용 |
|---|---|
| 이동 | 주인공 곁의 정해진 자리(슬롯)로 따라붙는다. 너무 멀어지면(10칸) 곁으로 순간이동 |
| 공격 | 자기 장수의 **시작 무기**로 알아서 공격 (주인공과 같은 무기 클래스, 이펙트/투사체 풀은 주인공 것을 공유) |
| 공격력 | 장수 공격력 보정 x **0.6** (주인공이 중심이 되도록) |
| 성장 | 주인공 레벨이 3 오를 때마다 아군 무기도 1레벨 상승 |
| 체력 | **70 + 장수 체력 보정**, 받는 피해 x 0.7, 피격 후 0.5초 무적 |
| 쓰러짐 | 체력이 0이 되면 쓰러져 공격하지 못하고 적도 노리지 않는다. **15초 뒤** 주인공 곁에서 체력 50%로 부활(2초 무적) |
| 표시 | 머리 위 체력 막대(쓰러진 동안은 부활까지 진행률, 푸른색), 걷기 그림은 장수의 걷기 시트 |
| 스킬 | 아군은 장수 고유 스킬을 쓰지 않는다 (무기만) |

수치는 모두 `Assets/Scripts/Ally/AllyConfig.cs` 한 곳에 있다.

## 적과의 관계

- 적은 **주인공과 쓰러지지 않은 아군 중 가장 가까운 쪽**을 쫓는다. 닿으면 그 대상이 접촉 피해를 입고, 궁병은 그 대상을 향해 쏜다.
- 궁병 화살도 아군에게 명중한다 (쓰러진 아군은 통과).
- 주인공에게 닿지 않은 적은 주인공에게 피해를 주지 못한다 → 아군이 앞에서 적을 끌어 주는 효과가 있다.

## 구조 (참고)

| 클래스 | 역할 |
|---|---|
| `AllyConfig` | 수치 상수, 자리(슬롯) 좌표 |
| `AllyController` | 아군 본체: 따라가기, 무기, 체력/쓰러짐/부활, 걷기 애니메이션, 체력 막대 (`IEnemyTarget`, `IWeaponStats`) |
| `AllyManager` | 아군 생성/삭제, EnemyManager 등록, 주인공 레벨 연동 |
| `IEnemyTarget` | 적이 노릴 수 있는 대상 (주인공 외). `EnemyManager.RegisterTarget` 으로 등록 |
| `IWeaponStats`, `WeaponFactory` | 무기가 주인공 전용 구조에서 벗어나 아군도 쓸 수 있게 한 일반화 |
| `AllySelectUI` (`IAllySelectView`) | 아군 선택 화면 |
| `HeroSelectController` | 장수 선택 뒤 아군 선택을 이어 붙이고, 확정하면 `AllyManager.Spawn` |

## 셋업

메뉴 **Samkuk > Step 10-8 - Setup Allies (Mercenary Heroes)** 가 게임 씬에 아군 선택 화면(HUD)과 `AllyManager`(GameSystems)를 만든다
(Run All 에 포함, 여러 번 실행해도 안전). 장수 선택 셋업(Step 8)을 다시 돌려도 `HeroSelectController` 가 실행 중에 아군 UI/매니저를 찾으므로 깨지지 않는다.
