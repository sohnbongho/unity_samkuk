# 내정: 성 46곳과 배경 그림 (Step 12-1)

삼국지3의 내정(도시 관리) 모드를 위한 **성 데이터와 배경 그림**입니다. 이 단계에서는 "성이 있고, 이름/위치/인접 관계/배경이 있다"까지만 만들었고,
농업/상업/병력 같은 내정 수치와 화면은 다음 단계입니다.

## 구성

| 무엇 | 어디 |
|---|---|
| 기준표 (이름, 한자, 주, 지형, 크기, 위치, 연결) | `tools/castle_art/castles.json` |
| 배경 그림 생성기 | `tools/castle_art/CastleArt.cs`, `generate.ps1` |
| 배경 그림 46장 (1920x1080) | `Assets/Sprites/Castles/Castle_<id>.png` |
| 성 데이터 | `Assets/ScriptableObjects/Castles/Castle_<id>.asset` (`CastleData`) |
| 성 목록 | `Assets/ScriptableObjects/CastleCatalog.asset` (`CastleCatalog`, `Find(id)`) |
| 셋업 | 메뉴 `Samkuk > Step 12-1 - Castles (내정 성 + 배경)` (Run All 에도 포함) |
| 테스트 | `Assets/Tests/PlayMode/CastleTests.cs` |

## 성 목록 (46곳)

삼국지3처럼 도시 46곳을 후한 말 지리에 맞춰 배치했습니다. 정확한 원작 목록을 옮긴 것은 아니므로 **자유롭게 고쳐도 됩니다**(아래 "성 추가/수정").

| 주 | 성 |
|---|---|
| 유주 | 양평, 북평, 계 |
| 기주 | 남피, 업 |
| 청주 | 평원, 북해 |
| 병주 | 진양, 상당 |
| 사례 | 하동, 하내, 낙양(도성), 홍농, 장안(도성) |
| 양주(涼) | 천수, 안정, 무위 |
| 연주 | 진류, 복양 |
| 예주 | 허창, 여남 |
| 서주 | 소패, 하비 |
| 형주 | 완, 신야, 양양, 강하, 장사, 계양, 영릉 |
| 익주 | 한중, 성도, 자동, 강주, 영안, 건녕, 영창 |

## 배경 그림이 정해지는 방식

한 장은 위에서부터 **하늘 → 먼 산 3겹 → 들판 → 강(선택) → 길 → 성 → 앞쪽 나무/바위** 순서로 겹쳐 그립니다.

- **지형**(`terrain`): 평야/초원/산악/강변/남방/황토 여섯 가지가 땅색, 산 높이, 나무 종류를 정합니다. 산악은 양옆에 절벽, 남방은 야자수, 초원은 풀숲과 바위가 나옵니다.
- **크기**(`size`): 0소 / 1중 / 2대 / 3도성. 성벽 폭과 높이, 본성 층수가 커지고 도성(낙양, 장안)은 황금 지붕과 붉은 깃발입니다.
- **강**(`water`): 성 앞에 강이 흐르고 길이 다리로 건넙니다. 강변 지형은 넓은 강에 돛단배가 여러 척 뜹니다.
- **시간대**: 낮 / 해질녘 / 새벽을 성 id 로 정합니다. **같은 id 는 항상 같은 그림**이 나옵니다.
- 문루 현판과 본성 깃발에 성의 한자 이름이 들어갑니다. 글꼴은 설치된 것 중 `KaiTi > SimSun > Microsoft JhengHei > Microsoft YaHei > Malgun Gothic` 순으로 고릅니다.

## 작업 방법

### 그림 다시 만들기

```
powershell -File tools\castle_art\generate.ps1                  # 46장 전부
powershell -File tools\castle_art\generate.ps1 -Only Luoyang    # 한 곳만
```

결과 모아보기는 `%TEMP%\castle_backgrounds_sheet.png` 에 저장됩니다.
**직접 그린 그림이나 AI로 만든 그림으로 바꿨다면 그 성은 `-Only` 로 피해서 실행하세요.** (같은 이름의 파일을 덮어씁니다.)

### 그림을 직접 바꾸기

같은 이름(`Castle_<id>.png`, **16:9**, 1920x1080 권장)으로 덮어쓰면 됩니다. 가져오기 설정(스프라이트, 압축, 밉맵 없음)은 `CastleBackgroundImporter` 가 자동으로 맞춥니다.
다른 이름을 쓰려면 성 에셋의 `Background` 칸에 직접 끌어 넣으세요(셋업은 이미 연결된 배경을 덮어쓰지 않습니다).

### 성 추가/수정

1. `tools/castle_art/castles.json` 의 `castles` 에 한 줄 추가(또는 수정), 연결은 `links` 에 `"아이디-아이디"` 로 추가합니다. (양방향이라 한 번만 적습니다.)
2. `generate.ps1 -Only <id>` 로 그림을 만든 뒤, 메뉴 `Step 12-1` 을 실행합니다.
3. `CastleTests` 의 `ExpectedCount` 를 새 성 수에 맞춥니다.

셋업은 **멱등**입니다. 이미 있는 성의 이름/위치/크기 값은 덮어쓰지 않으므로, 이미 만들어진 성의 값을 바꾸려면 **에셋을 직접 고치세요**(기준표만 바꿔서는 반영되지 않습니다). 연결은 기준표에 있는 것을 추가만 하고, 에셋에서 직접 뺀 연결도 셋업을 다시 돌리면 되살아납니다.

## 메모리 / 용량

배경은 압축해서 가져오지만 `CastleData` 가 `Sprite` 를 직접 참조하므로 **카탈로그를 로드하면 46장이 함께 로드**됩니다(압축 후 약 50MB). 내정 화면에서 문제가 되면 배경을 `Resources`/Addressables 로 지연 로드하도록 바꾸세요.

# 내정 화면: 전략 지도 + 성 화면 (Step 12-2)

타이틀의 **[내정]** 버튼으로 들어가는 화면입니다. 아직 내정 수치와 명령은 없고, "지도에서 성을 고르고, 성 안으로 들어가 배경을 보고, 인접한 성으로 옮겨 다닌다"까지입니다.

## 쓰는 법

| 화면 | 동작 |
|---|---|
| 전략 지도 | 성 마커를 누르면 **선택**(오른쪽에 이름/주/지형/크기/배경 미리보기/인접한 성), 선택한 성을 **다시 누르거나** [성에 들어가기] → 성 화면 |
| 성 화면 | 배경 그림 + 위 띠(성 이름) + 아래 띠(**인접한 성 버튼**: 누르면 그 성으로 이동). [지도로 / ESC] |
| ESC | 성 화면 → 지도 → 타이틀 |

지도의 마커 색은 주(州) 색, 크기는 성 규모(소/중/대/도성)입니다. 선택한 성은 금색 고리가 생기고, 그 성에 이어진 길이 굵은 금색으로 바뀝니다.
타이틀로 나갔다가 다시 들어오면 마지막에 보던 성이 선택된 채로 열립니다(성 안이 아니라 지도에서).

## 구성

| 무엇 | 어디 |
|---|---|
| 규칙(선택/입장/이동) | `Assets/Scripts/Strategy/StrategyModel.cs` (화면 없이 테스트 가능) |
| 화면 | `Assets/Scripts/Strategy/StrategyUI.cs` — **화면 전체를 실행 중에 코드로 만든다** |
| 씬 | `Assets/Scenes/StrategyScene.unity` (카메라, 이벤트 시스템, 캔버스 + `StrategyUI` 뿐) |
| 지도 그림 | `Assets/Sprites/Strategy/StrategyMap.png` (2560x1440) ← `tools/castle_art/MapArt.cs` |
| 셋업 | 메뉴 `Samkuk > Step 12-2 - Strategy Scene` (Run All 에도 포함) |
| 타이틀 버튼 | 메뉴 `Step 9-2` 를 **다시 실행**해야 [내정] 버튼이 생긴다 (버튼 배치가 바뀌었으므로 Run All 권장) |
| 테스트 | `Assets/Tests/PlayMode/StrategyTests.cs` |

빌드 설정 순서: 타이틀(0) → 게임(1) → 내정(2).

## 지도 그림이 정해지는 방식

바다 + 해안선 안쪽 땅을 **가장 가까운 성의 주 색**으로 나눠 칠하고(경계는 짙은 선), 황하(누런색)/장강/한수/회수, 태행·진령·촉·남령 산줄기, 주 이름 한자를 얹었습니다.
성 마커 위치는 `castles.json` 의 `x, y` 가 그대로 쓰이므로 **성 위치를 바꾸면 그림도 다시 만들어야** 영역과 맞습니다(`generate.ps1 -Only Map`, 그다음 에셋 위치는 성 에셋의 `Map Position` 을 직접 고칠 것 — 셋업은 기존 성 값을 덮어쓰지 않습니다).
직접 그린 지도로 바꾸려면 같은 이름(`StrategyMap.png`, **16:9**)으로 덮어쓰고, 이후 `generate.ps1` 은 `-Only <성 id>` 로만 실행하세요.

## 다음 단계로 이어 붙일 곳

- 내정 수치/명령: 성 화면 아래 띠의 안내 문구(`Note`) 자리에 명령 버튼을 둔다. 수치는 `CastleData`(고정 정보)와 따로 **저장되는 성 상태**를 두는 쪽이 좋다(영구 저장은 `SaveData`).
- 성 소유/세력: 지금은 모든 성이 주 색으로만 구분된다.

## 해상도 (Step 12-3)

- **그림**: 성 배경은 **1920x1080**, 전략 지도는 **2560x1440** 으로 키웠습니다. 성 그림은 그리는 좌표(1280x720)를 1.5배로 확대해 그리므로 구도는 그대로고 선이 선명해졌습니다. 직접 그린 그림은 16:9 이기만 하면 됩니다(크기는 자유, 1920x1080 이상 권장).
- **내정 화면 UI**: 기준 해상도가 **2560x1440** 입니다(타이틀/HUD 는 1920x1080 그대로). 지도 영역이 1960x1102 로 넓어져 성 마커/이름이 덜 겹치고, 성 화면 아래 띠에 명령을 넣을 공간이 늘었습니다. 기준 해상도는 `StrategyUI.ReferenceResolution` 한 곳이며 씬의 CanvasScaler 값을 실행 때 덮어씁니다.
- **화면 설정(타이틀 왼쪽 위 버튼)**: `해상도`(1280x720 ~ 3840x2160, 모니터보다 큰 것은 제외)와 `화면`(창 모드 / 전체화면 / 전용 전체화면)을 누를 때마다 순환하고 저장합니다. 기본값은 이전과 같은 1920x1080 테두리 없는 전체화면이며, 이 모드는 바탕화면 해상도를 쓰므로 해상도 버튼은 "자동"으로 꺼집니다. 해상도를 고르려면 창 모드나 전용 전체화면으로 바꾸세요. 규칙은 `DisplaySettings`, 저장은 `SaveData.displayWidth/displayHeight/windowMode`. 에디터에서는 게임 뷰를 건드리지 않고 빌드(실행 파일)에서만 실제로 적용됩니다.

# 시작 성 선택과 출진 (Step 12-4, 출진 규칙은 12-5 에서 정복으로 확장됨)

내정을 처음 열면 **시작할 성을 고르고**, 그 성이 "내 성"이 됩니다. 내 성의 성 화면에서 **[출진]** 을 누르면 그 성의 지형으로 서바이버 전투가 시작됩니다.

## 흐름

1. **전략 지도**: 내 성이 없으면 안내문이 "시작할 성을 고르세요"로 바뀌고, 오른쪽 큰 버튼이 **[이 성에서 시작]** 입니다. 성을 고른 뒤 이 버튼을 누르거나 **같은 성을 다시 누르면** 그 성이 내 성이 되고 곧바로 성 화면으로 들어갑니다. 내 성은 지도에서 **★** 로 표시됩니다.
2. **내 성이 정해진 뒤**: 큰 버튼은 **[성에 들어가기]** 로 돌아가 다른 성도 구경할 수 있습니다(내 성은 바뀌지 않음). 지도 위쪽의 **[시작 성 변경]** 으로 내 성을 취소하고 다시 고를 수 있습니다.
3. **성 화면**: 내 성에서만 아래 띠 오른쪽에 **[출진 (전투 시작)]** 이 보입니다. 다른 성에서는 "내 성이 아닙니다"라는 안내만 나옵니다.
4. **전투**: 바닥에 그 성 지형의 색이 덮입니다(`BattleTerrain`: 평야 밝은 초록, 초원 마른 풀색, 산악 회색, 강변 청록, 남방 짙은 초록, 황토 누런 흙). 타이틀의 **[시작]** 은 이전처럼 **성 없이** 시작하는 판(기본 배경)입니다.
5. **결과 화면**: 출진한 판은 "출진 성"이 요약에 나오고 **[내정으로 (M)]** 버튼이 생깁니다. [다시 하기]는 같은 성에서 다시 출진합니다.

## 구성

| 무엇 | 어디 |
|---|---|
| 내 성/출진 규칙 | `StrategyModel` (`StartHere`, `ClearHome`, `CanSortie`, `Sortie`, `SortieStarted`) |
| 내 성 저장 | `SaveData.homeCastleId` (저장 초기화 시 함께 지워짐) |
| 출진한 성 전달 | `GameSession.SortieCastle` (타이틀 [시작]이 비움) |
| 전투 지형 색 | `BattleTerrain`(색표) + `InfiniteBackground.ApplyTerrainOverlay`(배경 위 반투명 한 겹) |
| 결과 화면 | `RunResult.castleName`, `ResultUI.SetStrategyReturn`, `GameManager.GoToStrategy` (M 키) |
| 테스트 | `StrategyTests`(내 성/출진), `SortieTests`(지형, 결과 화면, 타이틀 시작) |

결과 화면의 [내정으로] 버튼은 **씬에 만들어져야 하므로 Step 9(또는 Run All)를 다시 실행**해야 보입니다. 지형 색은 코드가 실행 때 입히므로 씬을 다시 만들 필요가 없습니다.

## 다음 단계로 이어 붙일 곳

- 출진 결과를 성에 반영(승리하면 보상/수치 변화 등)은 아직 없습니다. 지금은 전투가 성과 독립적으로 끝납니다.
- 내 성이 정해졌을 때 [시작 성 변경]은 확인 없이 바로 취소됩니다. 성별 상태가 저장되기 시작하면 확인 단계를 넣을 것.

# 정복: 공격할 성을 정하고 차지하기 (Step 12-5)

12-4 의 출진을 확장했습니다. 이제 **내 영토의 성에서 이웃한 적 성 하나를 골라 공격**하고, **이기면 그 성을 차지**합니다. 차지한 성은 내 영토가 되어 다음 출진의 출발점이 됩니다. 46곳을 모두 차지하면 **천하 통일**입니다.

## 규칙

- **영토**: 시작 성(내 성)과 정복한 성들입니다(`SaveData.ownedCastleIds`, 시작 성도 포함). 지도에서 영토의 성은 **금색 테두리**, 공격할 수 있는 성(영토와 이웃한 적 성)은 **붉은 테두리**, 나머지는 기본 색입니다. 오른쪽 정보 상자에 "★ 내 성 / ● 우리 성 / ▶ 적의 성 (공격 가능) / 적의 성"이 나오고, 지도 위쪽에 **보유 성 n / 46** 이 표시됩니다.
- **출진**: 우리 성의 성 화면에서 **[출진]** 을 누르면 **공격 대상 선택창**이 뜹니다(이 성과 이웃한 적 성 목록, 규모·지형 표시). 성을 고르면 전투가 시작됩니다. 이웃이 모두 우리 성이면 "공격할 수 있는 성이 없습니다"만 나옵니다. ESC나 [취소]로 닫습니다.
- **전투**: 바닥과 지형 오브젝트가 **공격 대상 성의 지형**으로 정해집니다 (12-6, docs/TERRAIN.md)(`GameSession.SortieCastle` = 대상, `SortieOrigin` = 출발한 성).
- **승리** → 대상 성이 영토에 들어가고(`Territory.Conquer`, 결과 정산 때 저장) 결과 화면에 "정복 성공! / ★ ○○ 정복! (보유 성 n)"이 나옵니다. [내정으로]로 돌아가면 차지한 성이 선택되어 있습니다.
- **패배** → "퇴각했습니다 (성은 그대로)". 영토는 변하지 않습니다.
- **다시 하기**: 같은 대상을 다시 공격합니다. 이미 차지한 성을 다시 이겨도 중복으로 정복되지 않습니다(정복 문구도 없음).
- **시작 성 변경**: 다른 성을 하나라도 차지했으면 영토가 사라지므로 막고, 버튼도 숨깁니다. 영토 기능 이전의 저장(내 성만 있음)은 열 때 내 성을 영토로 쳐 줍니다.
- 타이틀의 **[시작]** 은 여전히 성 없이 시작하는 판이라 정복과 무관합니다.

## 구성

| 무엇 | 어디 |
|---|---|
| 영토 저장 규칙 | `Territory`(`IsOwned`, `Conquer`, `Release`, `Count`) — 순수 함수 |
| 영토/공격 규칙 | `StrategyModel`(`IsOwned`, `IsAttackable`, `AttackTargets`, `CanSortie`, `Sortie(target)`, `IsUnified`) |
| 정복 정산 | `ResultController.Settle`(승리 시 `Territory.Conquer`), `RunResult.conquered/ownedCount/castleName` |
| 화면 | `StrategyUI`(테두리 색, 보유 성 표시, 공격 대상 선택창 `TargetPanel`), `ResultUI`(정복/퇴각 문구) |
| 테스트 | `StrategyTests`(영토/공격/선택창), `SortieTests`(결과 문구), `MetaTests`(정복 정산 4개) |

결과 화면 상자를 키웠으므로(높이 780→840) **Step 9(또는 Run All)를 다시 실행**해야 반영됩니다. 내정 화면의 변경은 실행 때 코드가 만들므로 씬 작업이 필요 없습니다.

## 아직 없는 것 (다음 후보)

- **난이도**: 성 규모/지형이 전투 난이도에 영향을 주지 않습니다(바닥 색만 바뀜). 큰 성일수록 적이 강하게 하는 것이 자연스러운 다음 단계입니다. 밸런스 테스트(`BalanceTests`)와 함께 손봐야 합니다.
- **적의 반격/세력**: 적 성은 가만히 있고 주인(군주)이 없습니다. 성을 빼앗기는 일은 없습니다.
- **정복 보상/내정**: 차지한 성에서 얻는 것(골드, 수치)이 없습니다. 내정 수치 단계에서 붙입니다.
- **천하 통일 연출**: 지금은 지도 위쪽 문구만 "천하 통일!"로 바뀝니다.
