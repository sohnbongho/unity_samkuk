# 야전 (남코 삼국지2식 부대 전투, Step 15)

> **상태: 15-1 순수 로직, 15-2 격자·임시 그림 완료. 15-3 씬·화면 완료. 체감 조정·연출(15-4)은 아직.** 2026-11-01 설계 인터뷰(`/grill-with-docs`)로 정한 내용을 모았다. 코드는 `Assets/Scripts/Field/`(`Samkuk.Field`), 테스트는 `FieldBattleModelTests`. 용어는 `CONTEXT.md` "야전", 시점 결정은 `docs/adr/0003`.

성 밖 들판에서 **부대** 여러 개가 맞붙는 반자동 전투 모드. 시간이 실시간으로 흐르고, [정지]를 눌러 멈춘 상태에서 부대마다 **명령**(전진·대기·후퇴)을 주고 [재개]한다. 남코 삼국지2(覇王の大陸)의 합전이 본보기이며, 화면은 아이소메트릭(대각선) 격자다. **1단계는 독립 테스트 모드**로 만들고 출진·정복 흐름과는 연결하지 않는다.

### 병과 표 (1단계 기본값, `FieldUnitClassData` 에셋으로 조정)

| 병과 | 이동(칸/초) | 공격 | 초당 피해(명) | 특징 |
|---|---|---|---|---|
| 보병 | 1.0 | 인접 칸 | 20 | 받는 피해 x0.8 |
| 궁병 | 1.0 | 사거리 **3칸**(아군 너머로 쏨) | 14 | 인접한 적에게 주는 피해 x0.5 |
| 기병 | 2.0 | 인접 칸 | 28 | **돌격**: 멈춘 상태에서 전진해 처음 닿는 순간 60명 추가 피해 |
| 장수 부대 | 기병과 같음 | 인접 칸 | 기병 x1.3 | 상성에서 "궁병 > 기병" 을 받지 않음. 장수 능력치는 1단계에 안 씀 |

상성 배율: 강한 쪽이 주는 피해 **x1.5**, 약한 쪽이 주는 피해 **x0.6**. 교전은 턴 없이 초당 피해를 병사 수에서 빼고, 인접한 둘은 서로 피해를 입는다.

## 구현 기본값 (인터뷰에서 묻지 않고 정한 것)

- 격자 좌표 (col,row), 인접 = **4방향**(대각선 아님), 거리 = 맨해튼. 궁병 사거리도 맨해튼 3.
- 이동은 칸 단위 결정(목표 칸으로 보간해 그림만 부드럽게). 다음 칸이 차 있으면 **목표에 가까워지는 옆 칸**으로 비켜 가고, 비킬 곳이 없으면 그 자리에서 인접한 적을 때린다. 같은 틱에 두 부대가 같은 칸을 원하면 먼저 처리된 쪽이 차지한다.
- 적 쪽 "자기 진영 가장자리" 는 오른쪽 위, 내 쪽은 왼쪽 아래 가장자리.
- 숫자 키 1~9, 0 으로 부대 선택(부대 수가 가변이라 7 로 고정하지 않음).
- 그림: 마름모 타일 **48x24 픽셀**(PPU 32 → 1.5x0.75 유닛), 격자선 옅게, 지형별 색조 6종(`CastleTerrain`). 부대 그림은 병과 3종 x 진영 2 x 방향 2(↘·↗, 좌우 반전으로 4방향) x 걷기 2프레임, 칸 안에 병사 3~5명 무리(보병 창·방패, 궁병 활, 기병 말, 장수 부대는 기병 + 깃발). 피벗은 칸 바닥 가운데. `Assets/Sprites/Field/`, 임포터 Point·PPU 32.
- 교전 연출은 기존 `BurstFx`/화살 그림/`SfxId` 재사용. 부대 위 병사 수 숫자, 병과 아이콘, 현재 명령 표시, 내 편 파란 테·적 빨간 테, 선택 부대 강조, 목표에 표식 + 점선.

## 모델 구조 (15-1)

- `FieldBattleModel.Tick(dt)`: 정지·종료면 아무것도 안 함 → 적 AI 타이머(1초) → **공격**(모든 부대가 상대를 고른 뒤 한 번에 피해, 백병전은 인접·궁병은 사거리 3, 목표 우선) → 무너진 부대 정리(내 부대면 자동 정지, 장수 부대면 승패) → **이동**(이동 중이면 진행, 도착하면 기병 돌격 장전; 멈춰 있으면 명령대로 다음 칸 예약).
- 다음 칸 고르기 `StepToward`: 남은 거리가 큰 축 → 다른 축 → 옆 칸(정렬돼 있을 때) → 직전에 떠난 칸까지 허용. 이동 중인 부대는 출발·도착 칸을 둘 다 차지한다.
- 명령은 `SetOrder`(내 부대, 정지 중에만)와 `ForceOrder`(검사 없음: AI·테스트·연출). 시작은 전원 대기·정지.
- `CreateEmpty` + `AddUnit` 으로 임의 장면을 만들 수 있다(테스트, 뒤에 시나리오/튜토리얼).
- 화면이 쓸 것: `Units`, `VisualCol/VisualRow`(보간 위치), `FacingDx/Dy`, 이벤트 `Hit`(공격자·피해자·양·원거리·돌격, 매 틱이라 화면이 묶어서 표현), `UnitRouted`, `UnitExited`, `AutoPaused`, `FinishedEvent`.

## 여는 방법 (15-3)

1. 처음 한 번: 메뉴 **`Samkuk > Step 15 - Field Battle Scene (야전 테스트)`** 로 `FieldBattleScene`(빌드 4번)을 만든다 (`Run All Setup` 에도 포함). 장수 목록(Step 8)이 먼저 있으면 장수 이름을 쓰고, 그림은 `tools/field_art/generate.ps1` 이 만든 `Assets/Sprites/Field` 를 연결한다(없으면 색 덩어리로 동작).
2. 열기: 메뉴 **`Samkuk > Play Field Battle (야전 테스트 실행)`**, 또는 타이틀에서 Play → 왼쪽 아래 **[야전 테스트]** 버튼([맵 편집기] 위, 에디터와 개발용 빌드에서만).

## 화면과 조작 (15-3)

씬에는 고정 카메라(도트 규격, y = -0.9375 로 전장이 아래 명령 띠 위에 들어옴)·전역 조명·이벤트 시스템·`FieldBattleController`(그림 참조)만 있고, **화면은 `FieldBattleUI` 가 실행 중에 코드로 만든다**(기준 해상도 1920x1080, 명령 띠 높이 324 = 가상 해상도의 108픽셀).

| 화면 | 내용 |
|---|---|
| 준비 화면 | 장수(장수 부대 이름), 내/적 병과별 부대 수 0~3, 부대 병사 수(100/200/300/500/800), 내 배치(4종 x 반전), 적 배치(무작위 또는 고정), 적 AI 켬/끔, 지형(바닥 색). [시작] [타이틀로]. 마지막 값은 `FieldSession` 이 기억한다 |
| 야전 | 전장(마름모 타일 108칸 + 부대 그림, 발밑 테 = 선택(노랑)/목표(빨강)), 부대 위 병사 수 라벨(▲전진 ■대기 ▼후퇴, 내 편 파랑·적 빨강), 아래 명령 띠: 선택 부대 정보 / [전진][대기][후퇴] / [정지·재개 (Space)] [메뉴 (ESC)] 시간 / 안내 |
| 결과창 | 승리/패배, 남은 부대·병사 수, 걸린 시간. [다시](같은 조건) [준비 화면] [타이틀] |
| ESC 메뉴 | [계속](정지 상태 그대로) [준비 화면] [타이틀]. 메뉴를 열면 정지한다 |

| 조작 | 키 / 마우스 |
|---|---|
| 부대 선택 | 내 부대 클릭, 또는 숫자 키 `1`~`9`,`0`(살아 있는 내 부대 순서, 1 = 장수 부대) |
| 명령 | 정지 중에만. [전진][대기][후퇴] 버튼. **적 부대를 클릭하면 선택한 부대가 그 부대를 목표로 전진** |
| 정지 / 재개 | `Space` 또는 띠의 버튼. 시작은 전원 대기·정지 상태. 내 부대가 무너지면 저절로 정지(안내 줄에 표시) |
| 메뉴 | `ESC` |

클릭은 마름모 칸으로 집되(`IsoGrid.WorldToCell` → `FieldBattleModel.UnitAt`), 빈 칸이면 그림이 0.9유닛 안에 있는 가장 가까운 부대를 집는다(그림이 칸보다 위로 길어서). 정지는 모델 깃발이고 ESC 메뉴도 `timeScale` 을 건드리지 않는다. 결과창은 승패 뒤 1초에 뜬다.

## 그림 규격 (15-2, `FieldArtSpec`)

| 그림 | 파일 | 크기 | 비고 |
|---|---|---|---|
| 바닥 타일 | `Assets/Sprites/Field/Tile_<지형>.png` (Plain/Steppe/Mountain/River/Jungle/Loess) | 48x24 | 고전 2:1 마름모를 픽셀로 직접 찍어 이어 붙여도 틈이 없다. 피벗 가운데, PPU 32 → 1.5x0.75 유닛. 색은 `tools/terrain_art/terrain.json` 의 지형 바닥 색 |
| 부대 시트 | `Unit_<Infantry|Archer|Cavalry|General>_<Player|Enemy>.png` (8장) | 192x48 = 48x48 칸 4개 | 칸 순서 [앞모습 0, 앞모습 1, 뒷모습 0, 뒷모습 1]. 앞모습 = 오른쪽 아래로 오는 모습(얼굴 보임), 뒷모습 = 오른쪽 위로 가는 모습. 왼쪽 방향은 **좌우 반전**. 부대가 선 마름모 가운데는 칸 아래에서 12픽셀 위(피벗 (0.5, 0.25)). 실행 중에 자른다(에디터 슬라이스 없음) |

- 임시 그림은 `tools/field_art/generate.ps1`(`-Only tile|unit`)이 그린다(`FieldArt.cs`, 4배 확대로 그린 뒤 `PixelTools` 로 축소·색 단계 7·1픽셀 외곽선). 미리보기 `%TEMP%ield_art_preview.png`. 직접 그린 그림으로 바꾸면 그 종류는 다시 돌리지 말 것.
- 임포터 `FieldSpriteImporter`(`Assets/Scripts/Editor`)가 폴더 안 PNG 를 자동으로 맞춘다: Tile_* 는 단일 스프라이트(피벗 가운데), Unit_* 는 Default 텍스처, 둘 다 Point·PPU 32·압축 없음.
- 격자↔월드: `IsoGrid`. 열(col)이 늘면 오른쪽 위, 행(row)이 늘면 왼쪽 위. 가운데 칸 (5.5, 4) 이 원점, 전장 외곽 15.75x7.875 유닛. 이동 방향 → 그림 방향은 `IsoGrid.FacingFor`(+col 뒷모습, -col 앞모습 반전, +row 뒷모습 반전, -row 앞모습). 월드 y 가 클수록 먼 칸이라 기존 y 정렬(World 레이어)이 그대로 앞뒤를 맞춘다.
