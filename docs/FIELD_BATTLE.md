# 야전 (남코 삼국지2식 부대 전투, Step 15)

> **상태: 15-1 순수 로직, 15-2 격자·임시 그림, 15-3 씬·화면 완료. 15-4 연출 완료(Play 미확인). 15-5 수치 에셋 완료. 15-6 키보드 조작·양옆 부대 목록 완료. 15-7 장수 개성(능력치·무기 연출) 완료. 15-8 부대 그림을 장수 걷기 시트 규격으로 완료. 수치 조정은 체감 피드백 뒤.** 2026-11-01 설계 인터뷰(`/grill-with-docs`)로 정한 내용을 모았다. 코드는 `Assets/Scripts/Field/`(`Samkuk.Field`), 테스트는 `FieldBattleModelTests`. 용어는 `CONTEXT.md` "야전", 시점 결정은 `docs/adr/0003`.

성 밖 들판에서 **부대** 여러 개가 맞붙는 반자동 전투 모드. 시간이 실시간으로 흐르고, [정지]를 눌러 멈춘 상태에서 부대마다 **명령**(전진·대기·후퇴)을 주고 [재개]한다. 남코 삼국지2(覇王の大陸)의 합전이 본보기이며, 화면은 아이소메트릭(대각선) 격자다. **1단계는 독립 테스트 모드**로 만들고 출진·정복 흐름과는 연결하지 않는다.

### 병과 표 (1단계 기본값, 에셋 `Assets/ScriptableObjects/Field/FieldRules.asset` 으로 조정)

| 병과 | 이동(칸/초) | 공격 | 초당 피해(명) | 특징 |
|---|---|---|---|---|
| 보병 | 1.0 | 인접 칸 | 20 | 받는 피해 x0.8 |
| 궁병 | 1.0 | 사거리 **3칸**(아군 너머로 쏨) | 14 | 인접한 적에게 주는 피해 x0.5 |
| 기병 | 2.0 | 인접 칸 | 28 | **돌격**: 멈춘 상태에서 전진해 처음 닿는 순간 60명 추가 피해 |
| 장수 부대 | 기병과 같음 x 장수 이동 배율 | 인접 칸 | 기병 x1.3 x 장수 공격 배율 | 상성에서 "궁병 > 기병" 을 받지 않음. 병사 수 = 부대 병사 수 x 장수 병사 배율 (15-7, 아래 "장수 개성") |

상성 배율: 강한 쪽이 주는 피해 **x1.5**, 약한 쪽이 주는 피해 **x0.6**. 교전은 턴 없이 초당 피해를 병사 수에서 빼고, 인접한 둘은 서로 피해를 입는다.

**수치 고치는 법 (15-5, `FieldRulesData`)**: 위 표와 상성·장수 배율·적 AI 문턱(`aiInterval` 판단 간격 1초, `aiRetreatRatio` 후퇴 0.2, `aiGeneralAdvanceRatio` 적 장수 전진 0.5)은 모두 에셋 `FieldRules.asset` 의 필드다(`FieldRules` 클래스와 같은 이름). Step 15 가 **없을 때만** 기본값으로 만들고 야전 씬의 `FieldBattleController` 에 연결하므로 고친 값은 셋업을 다시 돌려도 남는다. 야전을 시작할 때마다 에셋의 객체를 모델에 넘기므로 **고친 값은 다음 야전(결과창 [다시])부터 적용**되고 값은 에셋에 저장된다(Play 중 진행 중인 야전에도 바로 반영되는지는 확인 항목). 기본값으로 되돌리려면 에셋을 지우고 Step 15 재실행. 병과 수치는 구조체(`ClassStats`)라 코드에 필드를 더하면 기존 에셋에서 0 으로 읽히니 그때도 에셋을 다시 만든다. 에셋이 없으면(테스트) 코드 기본값 `FieldRules.Default()`.

## 구현 기본값 (인터뷰에서 묻지 않고 정한 것)

- 격자 좌표 (col,row), 인접 = **4방향**(대각선 아님), 거리 = 맨해튼. 궁병 사거리도 맨해튼 3.
- 이동은 칸 단위 결정(목표 칸으로 보간해 그림만 부드럽게). 다음 칸이 차 있으면 **목표에 가까워지는 옆 칸**으로 비켜 가고, 비킬 곳이 없으면 그 자리에서 인접한 적을 때린다. 같은 틱에 두 부대가 같은 칸을 원하면 먼저 처리된 쪽이 차지한다.
- 적 쪽 "자기 진영 가장자리" 는 오른쪽 위, 내 쪽은 왼쪽 아래 가장자리.
- 숫자 키 1~9, 0 으로 부대 선택(부대 수가 가변이라 7 로 고정하지 않음).
- 그림: 마름모 타일 **48x24 픽셀**(PPU 32 → 1.5x0.75 유닛), 격자선 옅게, 지형별 색조 6종(`CastleTerrain`). 부대 그림은 병과 3종 x 진영 2 x 방향 2(↘·↗, 좌우 반전으로 4방향) x 걷기 2프레임, 칸 안에 병사 3~5명 무리(보병 창·방패, 궁병 활, 기병 말, 장수 부대는 기병 + 깃발). 피벗은 칸 바닥 가운데. `Assets/Sprites/Field/`, 임포터 Point·PPU 32.
- 교전 연출은 기존 `BurstFx`/화살 그림/`SfxId` 재사용. 부대 위 병사 수 숫자, 병과 아이콘, 현재 명령 표시, 내 편 파란 테·적 빨간 테, 선택 부대 강조, 목표에 표식 + 점선.

## 모델 구조 (15-1)

- `FieldBattleModel.Tick(dt)`: 정지·종료면 아무것도 안 함 → 적 AI 타이머(1초) → **공격**(모든 부대가 상대를 고른 뒤 한 번에 피해, 백병전은 인접·궁병은 사거리 3, 목표 우선) → 무너진 부대 정리(내 부대면 자동 정지, 장수 부대면 승패) → **이동**(이동 중이면 진행, 도착하면 기병 돌격 장전; 멈춰 있으면 명령대로 다음 칸 예약).
- 다음 칸 고르기 `StepToward`: 남은 거리가 큰 축 → 다른 축 → 옆 칸(정렬돼 있을 때) → 직전에 떠난 칸까지 허용. 이동 중인 부대는 출발·도착 칸을 둘 다 차지한다.
- 명령은 `SetOrder`(내 부대, 정지 중에만)와 `ForceOrder`(검사 없음: AI·테스트·연출). 시작은 전원 대기·정지.
- `CreateEmpty` + `AddUnit` 으로 임의 장면을 만들 수 있다(테스트, 뒤에 시나리오/튜토리얼).
- 화면이 쓸 것: `Units`, `VisualCol/VisualRow`(보간 위치), `FacingDx/Dy`, 이벤트 `Hit`(공격자·피해자·양·원거리·돌격, 매 틱이라 화면이 묶어서 표현), `UnitRouted`, `UnitExited`, `AutoPaused`, `FinishedEvent`.

## 여는 방법 (15-3)

1. 처음 한 번: 메뉴 **`Samkuk > Step 15 - Field Battle Scene (야전 테스트)`** 로 `FieldBattleScene`(빌드 4번)을 만든다 (`Run All Setup` 에도 포함). 장수 목록(Step 8)이 먼저 있으면 장수 이름을 쓰고, 그림은 `tools/field_art/generate.ps1` 이 만든 `Assets/Sprites/Field` 를 연결한다(없으면 색 덩어리로 동작).
2. 열기: 메뉴 **`Samkuk > Play Field Battle (야전 테스트 실행)`**, 또는 타이틀에서 Play → 왼쪽 아래 **[야전 테스트]** 버튼([맵 편집기] 위, 에디터와 개발용 빌드에서만).

|---|---|

| 조작 | 키 / 마우스 |

클릭은 마름모 칸으로 집되(`IsoGrid.WorldToCell` → `FieldBattleModel.UnitAt`), 빈 칸이면 그림이 0.9유닛 안에 있는 가장 가까운 부대를 집는다(그림이 칸보다 위로 길어서). 정지는 모델 깃발이고 ESC 메뉴도 `timeScale` 을 건드리지 않는다. 결과창은 승패 뒤 1초에 뜬다.

## 연출 (15-4, `FieldFx`)

규칙과 무관한 보여 주기만 모아 둔 곳. 모델 이벤트를 받아 표현하며 피해는 매 틱 일어나므로 간격을 둔다.

| 사건 | 표현 |
|---|---|
| 백병전 피해 | 맞는 부대마다 0.2초에 한 번: 불꽃 입자 2개(`BurstFx`, 전투와 같은 풀) + `Hit` 소리 + 부대 그림이 0.15초 붉게 번쩍임(`FieldUnitView.Flash`) |
| 궁병 사격 | 쏘는 부대마다 0.45초에 한 번: 코드로 만든 화살(12x2픽셀, 풀 32개)이 0.3초 동안 살짝 포물선으로 날아가 맞는 자리에서 작은 불꽃 + `Arrow` 소리 |
| 돌격 | 흰 고리 입자 10개 + `Explosion` 소리 + 강한 번쩍임 |
| 부대 무너짐 | 편 색 입자 20개(장수 부대 36개) + `Kill` 소리 |
| 자동 정지 | `PlayerHurt` 소리 + 안내 줄 |
| 승패 | `Victory` / `Defeat` 소리 |
| 정지 중 | 화면 위 가운데에 "정지 중 — 명령을 주고 Space 로 재개" 배너. 고른 부대의 **공격 범위**(궁병 3칸, 나머지 인접 칸)를 옅은 노란 마름모로 표시 |

소리는 새로 만들지 않고 기존 `SfxId` 를 재사용한다(실제 음원 교체는 `AudioManager.overrides`). 수치(간격, 입자 수)는 `FieldFx` 상수.

## 장수 개성 (15-7)

준비 화면에서 고른 장수(`HeroCatalog`)가 내 장수 부대에 개성을 준다. 적 장수 부대는 아직 배율 1·무기 연출 없음(2단계 적장 데이터).

| 장수 데이터(`HeroData`) | 야전 장수 부대 | 어디서 |
|---|---|---|
| `damageMultiplier` 공격력 배율 | 주는 피해 배율(돌격 포함) `FieldUnit.DamageMul` | `FieldHeroLink.Apply` → `FieldSetup.playerGeneralDamageMul` |
| `moveSpeedMultiplier` 이동 속도 배율 | 이동 속도 배율 `FieldUnit.SpeedMul` | `playerGeneralSpeedMul` |
| `maxHpBonus` 체력 보정(기본 100 기준) | 병사 수 배율 = (100 + 보정) / 100, 최소 0.2 | `playerGeneralSoldierMul` |
| `startingWeapon` 시작 무기 | 백병전 타격 때 무기 연출(`FieldWeaponShow`) | `FieldFx.Bind(model, weapon)` |

무기 연출은 서바이버 전투의 휘두르기·찌르기 규칙(`SwingMotion`/`ThrustMotion`)과 검기(`WeaponTrail`, `WaveSprites`), 들고 있는 그림(`heldSprite`)을 그대로 빌린다(규칙 없음, 피해는 모델이 준다). 장수 부대가 백병전으로 때릴 때 불꽃·타격음 대신 손 높이에서 맞는 적 쪽으로 무기를 휘두르고 검기가 나간다. 동작 중엔 새 타격을 받지 않아 그게 간격이 된다. 그림은 아이소메트릭 부대 옆이라 0.6배, 검기 비거리는 2.5유닛까지(`FieldWeaponShow.Scale/MaxTravel`).

| 무기 종류 | 모습 |
|---|---|
| 베기(관우 청룡언월도, 유비 쌍고검) | 호를 그리며 베고 반원 검기. 유비는 검기가 멀리(2.5유닛) 난다 |
| 연속 베기(조조 의천검) | 내려친 뒤 올려치기를 이어서, 베기마다 검기 |
| 찌르기(장비 장팔사모) | 당겼다 내지르고 뾰족한 검기 |
| 극(여포 방천화극) | 찌르기와 휩쓸기를 번갈아 |
| 그 밖 | 베기로 (그림이 없으면 검기만) |

준비 화면의 장수 줄과 선택한 장수 부대의 띠 정보에 "공격 x / 이동 x / 병사 x / 무기" 한 줄이 뜬다. 값을 바꾸려면 `Hero_*.asset`(서바이버 전투와 공유).

## 그림 규격 (15-2, `FieldArtSpec`)

| 그림 | 파일 | 크기 | 비고 |
|---|---|---|---|
| 바닥 타일 | `Assets/Sprites/Field/Tile_<지형>.png` (Plain/Steppe/Mountain/River/Jungle/Loess) | 48x24 | 고전 2:1 마름모를 픽셀로 직접 찍어 이어 붙여도 틈이 없다. 피벗 가운데, PPU 32 → 1.5x0.75 유닛. 색은 `tools/terrain_art/terrain.json` 의 지형 바닥 색 |
| 부대 시트 | `Unit_<Infantry|Archer|Cavalry|General>_<Player|Enemy>.png` (8장) | 192x192 = 48x48 칸 4열 x 4행 | **15-8 부터 장수 걷기 시트와 같은 규격**(`docs/HERO_WALK_SHEETS.md`): 열 = 걷기 프레임 0~3, 행 = 아래/위/왼쪽/오른쪽, PPU 32, 발 피벗(아래에서 8px). 야전은 **왼쪽/오른쪽 줄만** 쓴다(아이소메트릭 한 걸음은 화면에서 가로가 세로의 두 배라 두 군대가 마주 보는 모양). 자르기는 `HeroSpriteSet`. **내 장수 부대는 고른 장수의 시트(`HeroData.walkSheet`)를 그대로** 쓰고, 적 장수 부대는 `Unit_General_Enemy`. 몸이 약 1.25유닛이라 타일(1.5x0.75)보다 크고 뒷줄과 겹치지만 World 정렬(발 y)이 앞뒤를 맞춘다 |

- 임시 그림은 `tools/field_art/generate.ps1`(`-Only tile|unit`)이 그린다. 타일은 `FieldArt.cs`, 부대 시트는 `tools/hero_art/FieldSprites.cs`(`HeroArt` 의 partial: 적 시트와 같은 몸·병과 그림에 편 색만 파랑/빨강, 보병 투구+창, 궁병 두건+활, 기병 말+창, 장수 부대 금빛 투구+깃털+극에 흰 말/검붉은 말; 몸 크기 병사 36px·기병 38px·장수 40px). 미리보기 `%TEMP%\field_unit_preview.png`(부대), `%TEMP%\field_art_preview.png`(타일+시트). 직접 그린 그림으로 바꾸면 그 종류는 다시 돌리지 말 것. 진짜 그림으로 바꿀 때는 장수 걷기 시트와 같은 방법(`docs/HERO_WALK_SHEETS.md` "넣는 법")으로 같은 파일 이름에 덮어쓴다.
- 임포터 `FieldSpriteImporter`(`Assets/Scripts/Editor`)가 폴더 안 PNG 를 자동으로 맞춘다: Tile_* 는 단일 스프라이트(피벗 가운데), Unit_* 는 Default 텍스처(실행 중에 자름), 둘 다 Point·PPU 32·압축 없음.
- 격자↔월드: `IsoGrid`. 열(col)이 늘면 오른쪽 위, 행(row)이 늘면 왼쪽 위. 가운데 칸 (5.5, 4) 이 원점, 전장 외곽 15.75x7.875 유닛. 이동 방향 → 그림 방향은 `IsoGrid.FacingFor`(+col/-row 오른쪽, -col/+row 왼쪽: `IsoGrid.FacesLeft` → `FieldUnitView.WalkDirOf`). 월드 y 가 클수록 먼 칸이라 기존 y 정렬(World 레이어)이 그대로 앞뒤를 맞춘다.
