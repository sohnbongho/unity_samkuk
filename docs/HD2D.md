# HD-2D 스타일 전환 계획 (Step 14)

"옥토패스 트래블러2" 그래픽 스타일(HD-2D)로 전투 씬을 바꾸는 계획. 용어는 `CONTEXT.md`, 큰 결정의 이유는 `docs/adr/0001`, `0002`.
진행 상태는 `CLAUDE.md` 진행 상황 표가 기준이다.

|---|---|
| 목표 요소 | 필수: 픽셀 캐릭터, 후처리, 조명/그림자. 나중: 3D 디오라마. 제외: 물 반사 |

## 단계

1. **14-1 조명** (완료): 성 시간대·지형별 전역광 색조(`CastleMood`, `LightingPreset`, `BattleLighting`), `TerrainProp` 빛 값(깃대 횃불·유르트·연못 점광원, `TerrainPropSpawner`), 플레이어 빛. 스위치: 타이틀 [조명 연출], 게임 안 F5. 설명 `docs/TERRAIN.md` "조명".
2. **14-2 후처리** (완료): 전투 카메라에 `BattlePostFx`(셋업 `Step 14-2`), 코드로 만드는 Volume 프로필 `PostFxPreset`(블룸 문턱 1·비네트·대비/채도·시간대 색온도). 스위치: 타이틀 [화면 효과], 게임 안 F6.
3. **14-3 픽셀 파이프라인** (완료): `PixelArt`(PPU 32, 640x360, 칸 48) + `BattlePixelCamera`(Pixel Perfect Camera, 업스케일 없음, 셋업 `Step 14-3`) + 임포터 Point/PPU 32 + 공용 도트 도구 `tools/pixel/PixelTools.cs`(축소·알파 자르기·색 단계·외곽선)로 걷기 시트 15장(192x192)과 지형 50장(절반 크기) 재생성. 스위치: 타이틀 [도트 화면], 게임 안 F7. 공용 팔레트 파일은 두지 않고 채널당 색 단계(7~12)로 통일 — 진짜 그림이 올 때 팔레트를 정한다. 걷기 시트 PPU 는 시트 폭(192)으로 판단해 32 로 이전.
4. **14-4 서 있는 소품·월드 정렬·그림자** (완료): `TerrainProp.standing`(막는 소품 = 서 있는 소품, Step 12-6 이 채움), World 정렬 레이어 + 2D 렌더러 정렬 축 (0,1,0) + 피벗 기준점(셋업 `Step 14-4`), 걷기 시트 피벗 = 발(트랜스폼 = 발 위치), 드리운 그림자 `CastShadow`(회전·배율·회전 3단 전단, 시간대별 `ShadowPreset`, 적은 발밑 타원 옵션), 맵 편집기 서 있는 소품 회전 금지. 기존 소품 그림이 이미 옆모습이라 다시 그리지 않았다. 스위치: 타이틀 [그림자], 게임 안 F8.
5. **14-5 틸트 시프트** (완료): 첫 셰이더 `Assets/Shaders/TiltShift.shader`(화면 y 로 흐림 세기, 13탭 원판 흐림) + URP Full Screen Pass 렌더러 기능(2D 렌더러 에셋 하위, 후처리 전, 셋업 `Step 14-5` 가 추가) + `BattleTiltShift`(전투 카메라에서만 켜고 떠날 때 끔, 해상도별 반지름 `TiltShiftPreset`). 스위치: 타이틀 [미니어처 흐림], 게임 안 F9.

## Step 16: 2.5D 틸트 (2026-10-24, ADR 0003)

사용자가 참고 화면(Godot GridMap + Sprite3D 의 2.5D: 원근 카메라로 비스듬히 내려다본 바닥 위에 도트 캐릭터·나무가 서 있는 모습)으로 바꾸기로 했다.
**게임 로직의 좌표계는 탑다운 2D 그대로**(x 오른쪽, y 북쪽, 땅 z = 0, 위 = -z)이고 보는 방법만 바꾼다. 모두 스위치(타이틀 [2.5D 시점], `SaveData.hd2dTilt`, 게임 안 F10)로 켜고 끄며 끄면 가짜 3/4 시점으로 돌아간다.

| 항목 | 결정 |
|---|---|
| 카메라 | 바라보는 점(플레이어)에서 남쪽·위로 19유닛 물러나 55° 로 내려다보는 원근(세로 시야 30°). 값은 `TiltPreset` 한 곳. 픽셀 퍼펙트는 틸트에서 끔 |
| 렌더러 | 전투 카메라만 URP 3D 렌더러 `Assets/Settings/Renderer3D.asset`(Forward, 셋업 Step 16-1 이 만들어 URP 에셋 목록에 추가). 기본(0번)은 2D 렌더러 그대로라 타이틀/내정/맵 편집기는 영향 없음 |
| 서 있는 그림 | 캐릭터·서 있는 소품·손에 든 무기·체력 막대. **트랜스폼은 돌리지 않고 셰이더(`Samkuk/PixelSprite`)가 피벗(발)을 지나는 빌보드 평면에 세운다.** 재질 바꾸기는 `StandingSprite` 컴포넌트(`WorldSorting.Configure` 가 붙임). 컷아웃 + 깊이 쓰기 + 그림자 드리움, 반투명(흐려진 소품, 막대)은 알파 블렌드 변형 |
| 바닥 | 배경 타일·얼룩·강·연못·바닥 장식은 눕힌 채(z = 0.01) 그림자를 받는 바닥 재질. 정렬은 예전 정렬 레이어/순서 그대로(투명 정렬은 정렬 레이어가 거리보다 우선) |
| 빛·그림자 | 가짜 드리운 그림자(`CastShadow`)는 숨기고 방향광(딱 떨어지는 그림자)의 진짜 그림자. 해는 `ShadowPreset` 과 같은 자리(`TiltPreset.SunDirection`), 전역광 색조는 햇빛 0.6 / 환경광 0.45 로 나눔. 소품 점광원·플레이어 빛은 3D 점광원 |
| 높이 | 손 높이·체력 막대·횃불처럼 "위"가 필요한 곳만 `TiltView.Lift` 로 카메라 위쪽을 따라 올린다. 투사체·검기·보석은 아직 바닥에 눕힌 채(후속) |
| 범위 | 화면에 보이는 땅은 사다리꼴(북쪽이 멀다). 소품 생성 범위·적 스폰 링은 `TiltPreset.GroundFootprint` 로 맞춤. 컬링은 시야각을 8° 넓힌 행렬(`BattleTiltCamera`) |

### 단계

1. **16-1 틸트 카메라·서 있는 그림·3D 빛** (완료): 위 표 전부. `TiltPreset`/`TiltView`/`StandingSprite`/`BattleTiltCamera`, 셰이더 `PixelSprite.shader`, 셋업 `Step 16-1`(Run All 포함), 테스트 `TiltViewTests`.
2. **16-2 높이·절벽**: 맵 편집기에 높이 도구, 칸 높이로 바닥·절벽 옆면 메시 생성, 절벽 가장자리 막기(`TerrainCollision`), 경사로.
3. **16-3 그림**: 절벽·흙길·물 가장자리 타일 생성기(코드), 투사체·검기·보석 높이, 덤불·갈대 세우기, 진짜 픽셀 타일셋 교체.
4. 후속: 맵 편집기 틸트 미리보기, 내정·타이틀 적용.
