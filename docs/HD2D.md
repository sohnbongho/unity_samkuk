# HD-2D 스타일 전환 계획 (Step 14)

"옥토패스 트래블러2" 그래픽 스타일(HD-2D)로 전투 씬을 바꾸는 계획. 용어는 `CONTEXT.md`, 큰 결정의 이유는 `docs/adr/0001`, `0002`.
진행 상태는 `CLAUDE.md` 진행 상황 표가 기준이다.

## 합의한 결정 (2026-10-09)

| 항목 | 결정 |
|---|---|
| 목표 요소 | 필수: 픽셀 캐릭터, 후처리, 조명/그림자. 나중: 3D 디오라마. 제외: 물 반사 |
| 범위 | 전투 씬 먼저. 내정·타이틀은 후속 |

## 단계

1. **14-1 조명**: 성 시간대·지형별 전역광 색조, `TerrainProp` 빛 값(깃발·횃불 점광원). 스위치.
2. **14-2 후처리**: 전투 카메라 후처리 켜기, 코드로 만드는 Volume(블룸·비네트·색 보정), 성별 색온도. 타이틀 끄기 버튼.
3. **14-3 픽셀 파이프라인**: 임포터 Point·PPU 32, Pixel Perfect Camera, 생성기 3종 픽셀 규격(공용 팔레트), 걷기 시트 칸 48, 지형 타일·소품·강·얼룩 재생성. "규격·임포터·카메라" / "그림 재생성" 두 커밋.
4. **14-4 서 있는 소품·월드 정렬·그림자**: `TerrainProp` 서 있음 플래그, 막는 소품 6종 옆모습, 정렬 레이어 통합·정렬 축, 드리운 그림자 컴포넌트(캐릭터·소품 공용, 풀링), 맵 편집기 회전 금지.
5. **14-5 틸트 시프트**: 첫 셰이더 + 2D 렌더러 피처, 화면 Y 기준 흐림, 스위치, 성능 확인.

## 후속 (체감 뒤)

- 플레이어와 겹친 서 있는 소품 반투명
- 덤불·갈대 세우기
- 14-3 뒤 블룸 문턱 등 후처리 값 재조정
- 내정(성 배경 46장, 전략 지도)·타이틀에 같은 팔레트·후처리 적용
- 진짜 픽셀 아트로 교체(구매/외주/AI 손질)
- 가짜 3/4 시점이 부족하면 진짜 3D 틸트 재검토
