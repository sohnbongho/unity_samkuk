# 맵 편집기 (맵툴, Step 13)

성마다 전투 맵을 **직접 고치는 도구**입니다. 자동으로 만들어지는 맵(지형 소품, 강, 연못, 깃발, 바닥 얼룩)을 그대로 보면서 나무를 더하고, 바위를 옮기고, 강을 새로 그리고, 바닥 지형을 바꿀 수 있습니다. 저장하면 **전투가 같은 맵을 씁니다.**

## 여는 방법

1. 처음 한 번: 메뉴 **`Samkuk > Step 13 - Map Editor Scene (맵 편집기)`** 로 `MapEditorScene` 을 만든다 (`Run All Setup` 에도 포함). 성 에셋(12-1)과 지형 테마(12-6)가 먼저 있어야 한다.
2. 열기:
   - 메뉴 **`Samkuk > Play Map Editor (맵 편집기 실행)`** — 곧장 편집기로 실행한다 (끝나면 Play 시작 씬은 다시 타이틀로 돌아간다).
   - 또는 타이틀에서 Play → 왼쪽 아래 **[맵 편집기]** 버튼 (에디터와 개발용 빌드에서만 보이고 릴리스 빌드에는 없다).

## 화면

| 위치 | 내용 |
|---|---|
| 위 줄 | `◀ 성 이름 ▶` 성 바꾸기 (맨 앞은 **자유 전투** = 타이틀 [시작]의 맵), 바닥 지형, 격자, 맞춤(스냅), 실행 취소/다시, **저장**, **전투 테스트**, 타이틀 |
| 왼쪽 | 도구(배치/선택·이동/지우개), 지우개 반경과 대상, 선택한 물건 조작(크기, 회전, 반전, 복제, 삭제), 칸/전체 되돌리기 |
| 오른쪽 | 그림 팔레트: 지형 탭(평야, 초원, 산악, 강변, 남방, 황토, 공용)별 소품. 눌러서 고른다 |
| 아래 | 마우스 좌표, 칸 번호와 "직접 고친 칸/자동 생성", 안내 / 메시지 |

격자의 12x12 네모가 **칸**이다. **연한 초록 덮개가 씌워진 칸이 직접 고친 칸**이다. 가운데 흰 고리는 플레이어 시작 위치 주변(반경 2.5, 소품이 비는 곳)이다.

## 맵이 저장되는 방식

- **칸 단위로 덮어씁니다.** 칸을 처음 고치는 순간, 그 칸에 보이던 자동 생성 내용(소품, 얼룩, 강, 연못)이 그대로 "직접 고친 칸"으로 옮겨 와 거기서부터 편집됩니다. 고치지 않은 칸은 평소처럼 자동 생성이라 **세계는 계속 무한**하고, 고친 칸과 이웃 칸이 자연스럽게 이어집니다.
- 저장 파일은 성 아이디마다 JSON 하나 (`Xuchang.json`, 자유 전투는 `FreeBattle.json`): 고친 칸 목록과 물건(그림 이름, 위치, 크기, 회전, 반전, 색)만 들어 있다.
- 저장 위치 두 곳 (`MapStore`):
  1. `Application.persistentDataPath/maps/` — 이 컴퓨터에서 고친 맵. **먼저 읽힌다.**
  2. `Assets/Resources/Maps/` — 에디터에서 저장하면 같은 내용이 여기에도 써진다. **git 에 올리면 다른 사람/빌드에도 같은 맵이 적용된다.**
- 고친 내용을 전부 되돌려 저장하면(고친 칸 0개, 지형 그대로) 저장 파일이 지워지고 그 성은 다시 자동 생성 맵을 쓴다.
- **바닥 지형 바꾸기**: 성의 원래 지형 대신 다른 지형(타일, 소품 종류, 강 모양)을 쓴다. 직접 고친 칸의 내용은 그대로이고 나머지 칸이 새 지형으로 다시 만들어진다. 파일의 `terrain` 에 기록된다.
- 팔레트의 그림은 **스프라이트 파일 이름**으로 저장된다. 그림 파일 이름을 바꾸거나 지우면 그 물건은 맵을 열 때 건너뛴다.

## 전투 테스트

[▶ 전투 테스트] 는 저장한 뒤 그 성의 맵으로 전투를 시작한다. 시험 전투(`GameSession.MapTest`)에서는

- 결과 화면은 보이지만 **골드, 기록, 정복은 저장 데이터에 반영하지 않는다.**
- 왼쪽 아래에 안내가 뜨고 **`M`** 으로 편집기에 돌아온다 (결과 화면에서도 `M`). 타이틀 [시작], 내정 출진, 타이틀로 가기는 시험 모드를 끈다.

## 아직 없는 것

- **충돌/지형 효과**: 소품은 여전히 장식이다. 막는 지형은 전투 규칙과 함께 설계해야 한다.
- 여러 개 한꺼번에 선택(상자 선택)과 붙여넣기, 칸을 건너뛰는 큰 복사.
- 소품 외의 배치물(적 스폰 위치, 보물 상자 같은 이벤트 지점).
- 성 이름 검색 / 직접 고친 성 목록 보기 (지금은 ◀ ▶ 로 넘긴다).
