# 전투 맵: 성마다 다른 지형과 지형 오브젝트 (Step 12-6)

내정에서 어느 성을 공격하러 출진하느냐에 따라 **전투 맵이 달라집니다.** 이전에는 바닥에 지형 색을 한 겹 덮을 뿐이었고, 이제는 **지형별 바닥 타일 + 나무/바위/풀 같은 지형 오브젝트**가 맵 전체에 흩뿌려지며, 같은 지형이라도 **성마다 구성이 조금씩 다릅니다.**
타이틀의 **[시작]**(성 없이 시작한 판)도 빈 평지가 아니라 **평야 + 강이 있는 고정 맵**입니다(`TerrainMap.CreateFreeBattle`).

## 맵이 정해지는 방식

| 요소 | 정하는 것 |
|---|---|
| **바닥 타일** | 공격 대상 성의 **지형**(평야/초원/산악/강변/남방/황토) |
| **소품 종류** | 지형별 5가지 (예: 평야 = 나무, 덤불, 풀, 꽃, 바위 / 산악 = 소나무, 바위, 큰 바위, 덤불, 그루터기) |
| **소품 밀도** | 지형 기본값 x 성마다 0.8 ~ 1.3 (도성은 +10%) |
| **소품 비율** | 성마다 소품별 비중이 0.5 ~ 1.5배로 달라서 "어떤 나무가 많은 맵"인지가 다르다 |
| **바닥 색조** | 성마다 R/G/B 가 +-7% 안에서 조금씩 다르다 |
| **연못** | 강이 있는 성(`hasWater`)은 강 곁에 연못도 놓이고, 강변 지형은 조금 더 있다 (강 위에는 놓이지 않음) |
| **강** | 강이 있는 성(`hasWater`)과 강변 지형, 그리고 성 없이 시작한 판에 **구불구불 흐르는 강**이 있다. 방향, 굽이, 폭(±15%)이 성마다 다르고 지형마다 물색/강둑색/폭이 다르다 (황토 = 누런 황하) |
| **깃발** | 큰 성(대성)은 가끔, 도성(낙양, 장안)은 많이 꽂힌다 |

같은 성은 **항상 같은 맵**입니다(성 아이디로 정한 시드). 세계를 **12x12 유닛 칸**으로 나눠 칸마다 같은 배치를 계산하므로, 멀리 갔다가 돌아와도 같은 자리에 같은 나무가 있습니다.

## 강

- **모양**: 세계 전체에 같은 모양의 강이 **60유닛 간격으로 평행하게** 흐릅니다(사인 곡선으로 굽이침, 굽이 폭 2.5~4.5, 파장 26~40). 한 토막(256x128 그림 = 4x2유닛)을 1.5유닛 간격으로 **겹쳐** 이어 붙이고 흐르는 방향으로 눕히며, 물 밑에 더 넓은 **강둑** 토막을 깝니다(가장자리가 부드럽게 사라져 물가가 자연스럽습니다).
- **시작 위치**: 가장 가까운 강이 시작 위치에서 **약 10~17유닛** 떨어져 있어(걸으면 3~4초) 시작하자마자 물에 닿지 않고, 곧 화면에 들어옵니다. 시작 위치 주변은 항상 마른 땅입니다.
- **소품과 강**: 나무, 바위 등은 강물 위에 서지 않고, 연못도 강과 겹치지 않습니다.
- **건널 수 있는 장식**: 지금은 강도 충돌이 없어 **그대로 걸어서 건넙니다**(느려지지도 않음).
- 검증: 3만 개 성으로 시뮬레이션해 가장 넓은 강(5유닛)에서도 시작 위치가 물에 닿지 않는 값(10~13)을 골랐고, 칸 경계에서 토막이 겹치거나 끊기지 않는 것도 확인했습니다.

## 지형 오브젝트는

- **장식**입니다. 충돌이 없어서 적과 플레이어가 그대로 지나가고, 전투 규칙(이동, 공격, 적 AI)에 영향이 없습니다.
- 배경 정렬 레이어에 그려져 **적, 플레이어, 투사체, 경험치 보석 뒤에** 깔립니다. 소품끼리는 아래쪽(y가 작은)이 위에 그려집니다.
- **플레이어 시작 위치 주변(반경 2.5)** 은 비어 있습니다. 소품끼리, 소품과 연못도 겹치지 않습니다.
- **화면 주변의 칸에만** 만들고, 멀어지면 풀로 돌려보냅니다(약 100~200개 안팎의 스프라이트).

## 구성

| 무엇 | 어디 |
|---|---|
| 기준표 (파일, 그리는 방식, 색, 비중, 밀도) | `tools/terrain_art/terrain.json` |
| 그림 생성기 | `tools/terrain_art/TerrainArt.cs`, `generate.ps1` |
| 그림 50장 | `Assets/Sprites/Terrain/` (`Ground_*.png` 256x256 이음새 없는 타일, `Prop_*.png` 소품, `River_<지형>_Water/Bank.png` 강 토막 12장, 투명 배경) |
| 데이터 | `Assets/ScriptableObjects/Terrain/Theme_<지형>.asset` 6개 (`TerrainTheme`), `Assets/Resources/TerrainThemeCatalog.asset` (`TerrainThemeCatalog`) |
| 맵 계산(순수 로직) | `Assets/Scripts/World/TerrainMap.cs` |
| 소품 생성/풀링 | `Assets/Scripts/World/TerrainPropSpawner.cs` |
| 배경에 적용 | `InfiniteBackground.ApplyCastle` (바닥 타일 교체 + 소품 루트 `TerrainProps` 생성) |
| 셋업 | 메뉴 `Samkuk > Step 12-6 - Terrain Themes` (Run All 에도 포함) |
| 테스트 | `Assets/Tests/PlayMode/TerrainTests.cs` |

전투 씬은 따로 연결할 것이 없습니다. 카탈로그를 `Resources` 에서 직접 불러 쓰므로 **씬을 다시 만들지 않아도** 되고, 카탈로그가 없거나 그림이 비어 있으면 이전의 **색 덮개 방식**으로 대신 동작합니다(`BattleTerrain`).

## 작업 방법

### 그림 다시 만들기

```
powershell -File tools\terrain_art\generate.ps1                 # 전부
powershell -File tools\terrain_art\generate.ps1 -Only Jungle    # 한 지형만 (Plain/Steppe/Mountain/River/Jungle/Loess, 공용은 Shared)
```

모아보기는 `%TEMP%\terrain_sheet.png` 에 저장됩니다. 직접 그린 그림으로 바꿨다면 그 지형은 `-Only` 로 피해서 실행하세요.
가져오기 설정(스프라이트, PPU 64, 바닥 타일은 Repeat + FullRect, 소품은 피벗이 바닥)은 `TerrainSpriteImporter` 가 자동으로 맞춥니다.

### 그림 직접 바꾸기

같은 이름(`Prop_Plain_Tree.png` 등)으로 덮어쓰면 됩니다. **소품은 바닥에 닿는 점이 그림 아래쪽 가운데(아래에서 6px 위)** 에 오게 그리고, **바닥 타일은 256x256 에 가장자리가 서로 이어지게** 그리세요. 다른 이름을 쓰려면 테마 에셋의 해당 칸에 직접 끌어 넣으세요(셋업은 이미 연결된 그림을 덮어쓰지 않습니다).

### 소품 추가/조정

1. `terrain.json` 의 해당 지형 `props` 에 한 줄 추가(파일 이름, kind, 색, weight, scaleMin/Max)하고 `generate.ps1 -Only <지형>` 으로 그림을 만든 뒤 `Step 12-6` 을 실행하면 **빠진 소품만 추가**됩니다.
2. 이미 만들어진 테마의 **밀도/비중 수치는 테마 에셋(`Theme_*.asset`)을 직접 고치세요**(셋업은 기존 값을 덮어쓰지 않습니다). 소품이 너무 많거나 적으면 `Props Per Chunk`, 특정 소품이 흔하거나 드물면 해당 `Weight`.
3. 새 그림 종류(kind)가 필요하면 `TerrainArt.cs` 에 그리는 함수를 추가합니다.

## 아직 없는 것 (다음 후보)

- **지형이 전투에 주는 효과**: 지금은 보기만 다릅니다. 강을 건널 때 느려진다거나, 산악에서 이동이 느려지는 식의 규칙은 없습니다.
- **막는 지형**: 소품에 충돌이 없습니다. 바위나 나무가 적의 길을 막으면 전투가 크게 달라지므로(적 AI/이동 처리와 함께 설계 필요) 일부러 장식으로만 두었습니다.
- **성마다 고유한 랜드마크**: 성별 시드로 배치만 달라질 뿐 특정 성의 고유 오브젝트(예: 낙양의 폐허)는 없습니다.
