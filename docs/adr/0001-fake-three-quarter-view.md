# 진짜 3D 틸트 대신 가짜 3/4 시점

HD-2D(옥토패스 트래블러2) 스타일로 바꾸면서, 카메라를 기울이고 지형을 3D 메시로 바꾸는 대신 **탑다운 2D 좌표계와 직교 카메라를 그대로 두고 막는 소품만 옆모습으로 세워**(서 있는 소품 + 월드 정렬 + 드리운 그림자) 비스듬히 보이게 하기로 했다. 뱀서류 게임성(원형 공격 범위, 상하좌우 같은 거리감, 수백 마리의 순수 로직 충돌)과 이미 만든 지형 시스템·맵 편집기·`TerrainCollision` 을 지키기 위해서다.

## 고려한 대안

- **진짜 3D 틸트**(원근 카메라, 평면/박스 지형, 빌보드 캐릭터): 가장 옥토패스답지만 지형·맵 편집기·충돌·스폰 좌표를 전부 다시 만들어야 하고 원형 범위가 타원으로 보인다. 가짜 3/4 시점이 부족하다고 느낄 때 별도 단계로 재검토한다.
- **탑다운 유지 + 연출만**: 작업은 가장 적지만 소품이 붙여 놓은 그림처럼 보여 HD-2D 인상이 약하다.
