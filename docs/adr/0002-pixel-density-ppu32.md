# 도트 밀도 PPU 32(가상 해상도 640x360)와 고해상도 효과

모든 월드 스프라이트의 기준을 **1유닛 = 32픽셀**(가상 해상도 640x360, 걷기 시트 칸 48x48, Point 필터)로 정하고, Pixel Perfect Camera 를 업스케일 렌더 텍스처 없이 써서 **스프라이트만 정수 배 격자에 맞추고 조명·그림자·입자·UI·후처리는 화면 해상도로** 남긴다. 지원 해상도(1080p 3배, 1440p 4배)에서 모두 정수 배가 되고, 수백 마리를 그리는 뱀서류에 맞는 크기이며, 나중에 구매·외주할 픽셀 아트도 32픽셀 기준이 가장 흔하기 때문이다. 게임 수치(유닛, 피격 반지름)는 바꾸지 않는다.

## 고려한 대안

- PPU 48(960x540): 더 세밀하지만 1440p 에서 정수 배가 아니다.
- PPU 64 유지(1280x720): 1080p 에서 1.5배라 픽셀 퍼펙트가 깨지고 도트 느낌이 약하다.
- 전부 저해상도로 그린 뒤 업스케일: 가장 싸지만 조명·이펙트까지 굵은 픽셀이 되어 레트로 콘솔 느낌에 가깝다.

## 결과

- 기존 그림(PPU 64/96, Bilinear, 안티앨리어싱 벡터)은 전부 다시 만든다. 생성기(`tools/*_art`)도 픽셀 규격으로 바꾼다.
- 걷기 시트 규격 문서(`docs/HERO_WALK_SHEETS.md`)와 임포터가 바뀌므로 직접 그린 그림을 준비할 때 새 규격을 따른다.
