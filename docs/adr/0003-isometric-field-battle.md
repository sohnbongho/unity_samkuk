# 야전은 아이소메트릭, 서바이버 전투는 3/4 시점

남코 삼국지2(覇王の大陸)식 **야전**(부대 단위 반자동 전투, 정지해서 명령)을 새 모드로 넣으면서, 야전 화면은 **진짜 아이소메트릭**(마름모 격자, 대각선 4방향 부대 그림)으로 그리기로 했다. ADR 0001 의 가짜 3/4 시점은 서바이버 전투에 그대로 남고, 두 시점이 **모드별로 공존**한다. 야전은 격자 위 부대 몇 개가 움직이는 별도 씬이라 서바이버의 좌표계·`TerrainCollision`·맵 편집기와 아무것도 공유하지 않으므로, 시점을 따로 두어도 기존 시스템을 건드리지 않는다. 도트 밀도는 ADR 0002 의 PPU 32 를 그대로 쓴다.

화면 맞춤: 가상 해상도 640x360(20x11.25 유닛)에 전장 전체가 고정 카메라로 들어와야 하므로 마름모 타일은 **48x24 픽셀**(1.5x0.75 유닛), 격자는 **12x9 칸**이다(전장 외곽 504x252 픽셀, 아래 108 픽셀은 명령 띠). 64x32 타일 + 16x12 칸은 28x14 유닛이라 화면을 넘는다.

## 고려한 대안

- **3/4 시점 유지 + 격자만 대각선으로 기울임**: 기존 걷기 시트를 재사용할 수 있지만, 마름모 바닥 위에 정면 캐릭터가 서 있어 "대각선 전장"이라는 남코 인상이 나지 않는다. 야전 그림은 어차피 "병사 무리" 아이콘을 새로 그려야 해서 재사용 이득도 작다.
- **64x32 타일 + 16x12 격자, 이 씬만 가상 해상도 1280x720**: 전장은 넓어지지만 도트가 다른 씬의 절반 크기로 보이고 1080p 에서 정수 배가 깨져 Pixel Perfect 를 꺼야 한다. 도트 규격 통일(ADR 0002)을 지키기 위해 타일을 줄이는 쪽을 택했다.
- **서바이버 전투 안에 부대 명령을 섞기**: 한 씬에 두 놀이가 섞여 조작과 카메라가 충돌한다. 야전을 먼저 독립 테스트 모드로 만들고, 출진·정복 흐름과의 연결은 재미가 확인된 뒤 결정한다.
