# 가짜 3/4 시점 대신 진짜 2.5D 틸트 (2D 좌표계는 그대로)

사용자가 참고 화면(Godot GridMap + Sprite3D 의 2.5D: 원근 카메라로 비스듬히 내려다본 바닥 위에 도트 캐릭터·나무가 서 있는 모습)을 보고
그 스타일로 바꾸기로 했다(2026-10-24). ADR 0001 의 가짜 3/4 시점은 폐기한다. 다만 **게임 로직의 좌표계는 탑다운 2D 그대로** 둔다:
x 오른쪽, y 북쪽(화면 위), 땅은 z = 0, 땅에서 솟는 "위"는 -z(카메라 쪽). 바꾸는 것은 **보는 방법**뿐이다.

- 카메라: 바라보는 점(플레이어)에서 남쪽·위로 물러나 55° 로 내려다보는 **직교** 카메라(`TiltPreset`, 반높이 5.625). 처음엔 참고 화면처럼 원근이었으나, 수직으로 세워 세로를 늘린 키 큰 그림(나무)의 윗부분이 카메라에 가까워져 풍선처럼 커지고 화면 아래·위에서 납작한 정도가 달라 직교로 바꿨다(16-2). 직교는 도트 밀도가 화면 전체에서 같다. 픽셀 퍼펙트 카메라는 끈다.
- 렌더러: 전투 카메라만 URP 3D 렌더러(`Renderer3D.asset`)를 쓴다. 타이틀/내정/맵 편집기는 2D 렌더러 그대로.
- 서 있는 그림: 캐릭터·서 있는 소품·손에 든 무기는 **트랜스폼을 돌리지 않고 셰이더가 세운다**(`Samkuk/PixelSprite`, 피벗 = 발을 지나는 빌보드 평면).
  Rigidbody2D(Z 회전만 보존), 월드 정렬, 겹침 반투명, 풀링 코드가 그대로 돈다. 컷아웃 + 깊이 쓰기라 3D 에서 앞뒤가 자동이다.
- 그림자·빛: 가짜 드리운 그림자(`CastShadow`) 대신 방향광의 진짜 그림자. 해의 방향은 `ShadowPreset` 과 같은 자리에서 오고 전역광 색조는 햇빛/환경광으로 나눈다. 소품 점광원은 3D 점광원.
- 바닥: 배경 타일·얼룩·강·연못은 눕힌 채(z ≈ 0) 그림자를 받는 바닥 재질로 그린다. 높이(절벽)는 다음 단계(16-2).

## 고려한 대안

- **가짜 3/4 시점 유지 + 타일만 사진풍으로**: 기울어진 바닥 느낌이 안 난다. 사용자가 원한 것은 기울어진 시점이다.
- **좌표계를 XZ 바닥·Y 위로 바꾸는 완전 3D**: 모든 Vector2 로직·충돌·스폰·맵 편집기를 다시 써야 한다. 보는 방법만 바꾸면 순수 로직과 테스트가 그대로다.
- **트랜스폼을 돌려 세우기**: 적은 Rigidbody2D 가 루트에 있어 X 회전이 물리에 되돌려지고, 무기/막대/소품의 회전 코드를 전부 합성해야 한다. 셰이더로 세우면 호출처가 거의 없다.
- **로우폴리 3D 지형 에셋(구매 번들) 사용**: 픽셀 캐릭터와 섞이고 참고 화면과 다른 느낌이라 제외.

## 결과

- 원형 공격 범위가 타원으로 보이고 북쪽이 남쪽보다 멀리 보인다(스폰 링·소품 생성 범위는 사다리꼴에 맞춤). 상하 같은 거리감은 포기.
- 서 있는 그림의 컬링 범위는 눕힌 트랜스폼 기준이라 카메라 컬링 범위를 조금 넓혀 쓴다(`TiltPreset.CullMargin`).
- 서 있는 그림은 카메라를 향한 빌보드가 아니라 수직이다(기울인 빌보드는 상체가 절벽 벽면에 파고든다). 수직인 것은 기울기의 cos 만큼 납작해 보여 1/cos 으로 세로를 늘린다.
- 모든 것은 스위치(`SaveData.hd2dTilt`, F10)로 켜고 끄며, 끄면 ADR 0001 의 가짜 3/4 시점으로 돌아간다.
