# Unity 에서 Godot 4 (.NET) 로 전체 전환

사용자가 무료 엔진으로 옮기기로 했다(2026-11-13). 판정용 수직 슬라이스가 아니라 **전체 전환**이 목표이고,
Unity 원본(`main`, `features/tilt`)은 지우지 않고 브랜치 `features/godot` 의 `godot/` 폴더에서 작업한다.
같은 브랜치의 Unity 파일(`Assets/` 등)은 옮기는 동안 참고 원본으로 손대지 않는다.

- **엔진**: Godot 4.7.2 .NET (저장소 밖 `D:\01-AgentLegion\tools\godot\`, 공식 GitHub 릴리스, SHA512 확인). 렌더러는 Forward+ 로 시작.
- **언어**: C# 전부. GDScript 는 쓰지 않는다. 기존 2만 줄과 protobuf·csharpServer 공유를 지키려는 선택이며,
  대가로 **웹 내보내기를 못 하고 모바일은 실험 단계**다(대상이 PC 인 지금은 문제없음).
- **구조**: `godot/core`(`Samkuk.Core`, 엔진 참조 없는 순수 로직) / `godot/`(`Samkuk.Game`, 노드·화면·입력·소리) /
  `godot/tests`(`Samkuk.Tests`, `dotnet test` 로 엔진 없이). 순수 로직은 **호환 층**(`Samkuk.Compat`: 유니티와 같은 이름의
  `Vector2`·`Mathf`·`Color`·`Sprite`(경로·픽셀만 든 손잡이)·`ScriptableObject`·`Resources`·`JsonUtility`)을 써서
  `using UnityEngine;` 한 줄만 바꿔 옮긴다. 화면 층이 이 타입을 Godot 타입으로 바꾼다.
- **화면**: 2.5D 틸트(3D 노드) 한 가지만 옮긴다. 탑다운 2D 경로(F10 끔, Light2D, 가짜 드리운 그림자, 월드 정렬 축, 픽셀 퍼펙트 카메라)는 버린다.
  로직 좌표계(x 오른쪽, y 북쪽, 땅 z = 0, 위 = -z)는 그대로 두고 화면 층에서만 Godot 좌표로 바꾼다. 맵 편집기는 같은 3D 세계를 위에서 본다.
- **셋업 스크립트(33개)는 옮기지 않는다**: Godot 은 씬·리소스가 텍스트라 직접 만들어 커밋한다. 화면을 코드로 만드는 방식은 유지.
- **그대로 가는 것**: `TcpLink`/`Message.cs`/protobuf 3.27.3(NuGet), `save.json` 형식(위치만 `user://`), `SfxSynth` 코드 합성.
- **순서**: G0 뼈대 → G1 순수 로직·테스트 → G2 데이터·그림 → G3 전투 한 판 → G4 틸트 화면 → **사용자 확인(화면 품질·성능)** →
  G5 전투 나머지 → G6 타이틀·메타·소리·타격감 → G7 지형 → G8 내정 → G9 맵 편집기 → G10 로그인·협동 → G11 내보내기·대조.

## 고려한 대안

- **Unity 에 그대로**: Unity Personal 도 무료(연 매출 20만 달러까지)이고 옮기는 비용이 크다. 처음 추천은 이쪽이었으나 사용자가 전환을 택했다.
- **판정용 수직 슬라이스 먼저(전환은 그 뒤 결정)**: 가장 위험한 화면(틸트·셰이더·조명)을 먼저 확인하자는 안. 전체 전환으로 정하되 순서에 반영했다(G4 뒤 확인).
- **GDScript 또는 혼합**: 전부 다시 써야 하고 protobuf 를 따로 구현해야 하며 적 수백 마리 루프가 느리다.
- **순수 로직을 `System.Numerics`/Godot 타입으로 다시 쓰기**: 로직 6천 줄과 테스트 1만 6천 줄의 필드 이름(`x`/`X`)과 함수 이름이 전부 바뀐다.
  호환 층은 유니티식 이름이 Godot 프로젝트에 남는 대신 옮긴 코드가 원본과 줄 단위로 대조된다.
- **두 엔진 병행**: 혼자 하는 프로젝트에 유지 비용이 두 배.

## 결과

- Godot 은 명령줄·헤드리스 실행이 되어 임포트·테스트·실행 점검을 Claude 가 직접 한다(Unity 때는 사용자만 가능했다). 화면 품질은 여전히 사용자가 본다.
- 데이터(ScriptableObject 137개)의 Godot 쪽 형식은 G2 에서 정한다. 순수 로직이 엔진을 모르게 되었으므로 `.tres` 보다 JSON 이 맞을 수 있다(`godot/PORTING.md`).
- 유니티 PlayMode 테스트 중 게임 오브젝트·씬·에셋에 기대는 것은 `#if GAME_PORT` 로 미뤄 두고 해당 기능을 옮길 때 되살린다.
- 기존 Unity 저장 파일은 자동으로 가져오지 않는다.
